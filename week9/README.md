# AWS Cloud Incident Response: War Room Simulation (S27)

This project simulates how a security team responds to a live hacker attack inside an AWS cloud environment. It uses automated alerts to instantly detect security mistakes, isolate broken systems, and track down unauthorized changes.

 Technologies Used
* **AWS CloudTrail & GuardDuty:** For continuous behavior monitoring and intelligent threat detection.
* **AWS Config:** For near real-time tracking of infrastructure configuration drift.
* **Amazon Athena:** For executing targeted SQL forensic queries against raw security log dumps.
* **Linux Terminal & Bash:** To run quick containment commands and stop active threats.
